# 🎯 AI Placement Preparation Platform

An AI-powered platform that helps students prepare for campus placements.

## 🔗 Live Demo
[https://placement-support-system-production.up.railway.app](https://placement-support-system-production.up.railway.app)

## 🚀 Features
- 📄 AI Resume Review with ATS Score
- 🔍 Skill Gap Analysis
- 🗺️ Personalized Learning Roadmap
- 🎤 Mock Interview Agent (company-specific questions)
- 💻 Coding Recommendations by company
- 🏢 Admin Panel for Placement Officers

## 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot 3.3.5, Spring Security, JWT
- **Database:** PostgreSQL
- **AI:** Google Gemini API (gemini-2.5-flash)
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Railway
- **Tools:** Docker, Maven, Git

## ⚙️ Setup Instructions
1. Clone the repo
2. Copy `src/main/resources/application.properties.example` to `application.properties`
3. Fill in your database and API key values
4. Run PostgreSQL (Docker recommended)
5. Run `mvn spring-boot:run`
